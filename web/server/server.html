Self-hosting guide

Run the DNAnalyzer server yourself.

The optional Java server and CLI on your machine: batch runs, scripting, a private REST API.

Quick start REST API
Java 17+, one Gradle command, everything local.

The website itself needs no server.

Before you start

What you need.

A standard Java and Spring Boot app. Any modern JDK, or Docker.

Java 17 or newer

Runs the server and CLI. Check with java -version

2 GB RAM minimum

4 GB or more for large files.

Docker, if you like

No JDK needed. It all ships in the image.

Quick start

Build and run from source.

Clone, build with the Gradle wrapper, start. Listens on port 8080.

STEP 01

Clone the repository

git clone https://github.com/VerisimilitudeX/DNAnalyzer.git
cd DNAnalyzer
STEP 02

Make the Gradle wrapper executable

macOS and Linux, once. On Windows use gradlew.bat.

chmod +x ./gradlew
STEP 03

Run the server

bootRun builds and starts in one step. First run pulls dependencies.

./gradlew bootRun
STEP 04

Open the local server

The REST API is live at the address below, on your machine.

http://localhost:8080/api/v1/status

Build a standalone jar

Prefer one artifact? Build a boot jar, run it with Java.

./gradlew clean bootJar
java -jar build/libs/DNAnalyzer.jar

Run with Docker

Build the image, map port 8080. No JDK.

docker build -t dnanalyzer .
docker run -p 8080:8080 dnanalyzer
REST API

Every endpoint lives under /api/v1.

They accept sequence data, return deterministic JSON, all local.

MethodPathDescription
GET/api/v1/statusServer status and version
POST/api/v1/analyzeFull analysis of a sequence file
POST/api/v1/base-pairsCounts, percentages, GC content
POST/api/v1/reading-framesReading frames
POST/api/v1/find-proteinsCandidate protein coding regions
POST/api/v1/manipulateTransform, e.g. reverse complement
POST/api/v1/parseParse and validate a file

Check the server

A GET returns status and version.

curl http://localhost:8080/api/v1/status

Example response:

{
  "status": "running",
  "version": "1.0.0"
}

Analyze a base pair sequence

POST a sequence, get counts, percentages, GC content.

curl -X POST \
  http://localhost:8080/api/v1/base-pairs \
  -H "Content-Type: application/json" \
  -d '{"sequence":"ATGCATGCATGC"}'

Example response:

{
  "counts": { "A": 3, "T": 3, "G": 3, "C": 3 },
  "percentages": { "A": 25, "T": 25, "G": 25, "C": 25 },
  "gcContent": 50
}
Command line

The same engine, from your terminal.

For automation and reproducible research. Pass a file and analyses.

All flags in the CLI docs and the examples file.

java -jar build/libs/DNAnalyzer.jar \
  --gc-content \
  --base-composition \
  path/to/sequence.fa
Troubleshooting

If something goes sideways.

Port already in use

If 8080 is taken, pick another.

java -jar build/libs/DNAnalyzer.jar \
  --server.port=8090

Unsupported class version

Java older than 17. Check, then install a newer JDK.

java -version

Build failures

Clear cached files and rebuild. Confirm write access.

./gradlew clean
./gradlew bootRun
