Introduction

Two ways to run it, one deterministic engine.

The browser scores your DNA, nothing uploaded. For batch work, self-host the Java server and CLI.

Deterministic by design

Results come from documented formulas and cited data, not a model. Educational, not diagnostic.

System requirements

ComponentRequirement
BrowserChrome 80+, Firefox 75+, Safari 13+, Edge 80+
Memory2 GB minimum, 4 GB+ for large sequences
Java (server only)Java 17 or newer
Disk (server only)200 MB, plus space for your files

Reference

REST API reference.

Self-hosted endpoints under /api/v1 take sequence data, return deterministic JSON. See the self-hosting guide.

MethodPathDescription
GET/api/v1/statusServer status and version
POST/api/v1/analyzeFull analysis of an uploaded sequence file
POST/api/v1/base-pairsBase counts, percentages, and GC content
POST/api/v1/reading-framesReading frames for a sequence
POST/api/v1/find-proteinsCandidate protein coding regions
POST/api/v1/manipulateTransform a sequence, for example reverse complement
POST/api/v1/parseParse and validate a sequence file
POST/api/v1/analyze-geneticAnalyze a genotype export from a consumer test

GET /api/v1/status

Status and version.

curl http://localhost:8080/api/v1/status
{
  "status": "running",
  "version": "1.0.0"
}

POST /api/v1/base-pairs

Send a sequence, get counts, percentages, GC.

curl -X POST \
  http://localhost:8080/api/v1/base-pairs \
  -H "Content-Type: application/json" \
  -d '{"sequence":"ATGCATGCATGC"}'
{
  "counts": { "A": 3, "T": 3, "G": 3, "C": 3 },
  "percentages": { "A": 25, "T": 25, "G": 25, "C": 25 },
  "gcContent": 50
}

POST /api/v1/analyze

Form data: dnaFile for the file, options for a JSON flag string.

curl -X POST \
  http://localhost:8080/api/v1/analyze \
  -F "dnaFile=@sequence.fa" \
  -F 'options={"gc-content":true,"base-composition":true}'
{
  "sequence": { "length": 1234, "filename": "sequence.fa" },
  "basePairs": {
    "counts": { "A": 300, "T": 310, "G": 320, "C": 304 },
    "gcContent": 50.6
  }
}
Reference

CLI usage.

Run the jar. Pass a file and analyses as flags.

java -jar build/libs/DNAnalyzer.jar \
  --gc-content \
  --base-composition \
  path/to/sequence.fa

Common flags

FlagEffect
--gc-contentReport GC content
--base-compositionReport base counts and percentages
--reading-framesList reading frames
--find-proteinsFind candidate protein coding regions

More in the CLI examples file.
