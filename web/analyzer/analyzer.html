What this is, and what it is not
  • Deterministic, not AI. Fixed, documented algorithms ported from the DNAnalyzer Java engine. No model, no prediction.
  • On-device by default. Your file is read with the browser's FileReader and analyzed here, never sent to a server.
  • Educational tooling. ORF, protein and promoter results are simple scans, not curated annotation pipelines.
  • Cookieless analytics. Anonymous page views via Cloudflare Web Analytics, never anything about your sequence.
